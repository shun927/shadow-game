# ゲーム設計

このファイルはゲーム体験・ルール・未決定事項のメモです。Python/Unity/UDP などの技術構成は `system_architecture.md` に分けています。

## コンセプト
- 机の上に投影されたフィールドで、影の形や大きさを変えてキャラクターを操作しゴールを目指すゲーム
- 体験者はライト型デバイスを持ち、6DoFでトラッキングされる。様々な方向から照らすことが出来るようにする。

---

## フィールド
- サイズ：約30cm × 30cm
- 投影方法：プロジェクターを真下に向けて机に投影
- 物理的な影は使用しない。光・影はすべてUnity側で計算して投影する

---

## オブジェクト
- 積み木のようなオブジェクトが最初から配置されている（体験者が動かすインタラクションはなし）
- 各積み木にセーブポイントが設置されている

---

## ライト型デバイス
- 体験者が手に持つ
- 3D空間上の位置と照らしている方向を取得（6DoF）
- ボタンが1つある

---

## キャラクター
- 影の中にいることができる
- 影の外にしばらくいると死亡する
- 飛んでいる最中の死亡判定：未定

---

## 操作方法
- キャラの周囲を矢印が自動で回転し続ける（スロットマシーン方式）
- ボタンを押した瞬間の矢印方向にキャラがまっすぐ飛んでいく
- キャラが飛ぶときは「にゅんとつぶれる」アニメーションあり

---

## 影のシステム
- ライトの位置・方向（6DoF）をもとにUnityがリアルタイムで影を生成・投影
- キャラが通った軌跡は影（安全地帯）になる

---

## 死亡・リトライ
- 死亡すると直前のセーブポイントに戻る
- 直前の軌跡（影）のみ消える

---

## センシング構成
- Python AprilTag 2カメラトラッカーでライト型デバイスの 6DoF を取得する
- Python から Unity へ UDP JSON で送信する
- Unity 側では 30cm x 30cm フィールド中心を原点として扱う
- 座標対応は `Unity X = Python x`, `Unity Y = Python z`, `Unity Z = Python y`
- 最初のマイルストーンはゲーム本編ではなく、ライト位置・向き・照射点の入力可視化

詳細は `system_architecture.md` を参照。
