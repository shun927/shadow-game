# プロジェクト概要

## 目的

机上の 30cm x 30cm フィールドに Unity 画面を投影し、体験者が持つライト型デバイスの 6DoF 入力で影を操作するゲームを作る。

## 現在できていること

- AprilTag 36h11 を 2 台の Web カメラで検出できる。
- フィールド中心原点の `x/y/z` と姿勢を Python 側で取得できる。
- Python から Unity へ UDP JSON でトラッキング結果を送れる。
- Unity 側でライト位置・向き・フィールド面との照射点を可視化する初期シーンがある。

## 最初のマイルストーン

ゲーム本編ではなく、まず入力可視化を安定させる。

- 30cm x 30cm の実寸フィールドが Unity に表示される
- ライト型デバイスの位置がフィールド座標に合う
- ライトの向きと照射点が見える
- 通信が途切れたことが分かる

## 次のマイルストーン候補

- Unity 側でライトから仮の影領域を生成する
- キャラクターを置き、影の中/外判定を試す
- ボタン入力を追加する
- 回転矢印とジャンプ操作のプロトタイプを作る
- セーブポイントと死亡/リトライを設計する

## 役割分担

- Python: カメラ認識、AprilTag 検出、2カメラ統合、UDP送信
- Unity: 入力受信、座標変換、可視化、ゲームロジック、投影画面
- Docs: 仕様、構成、運用メモ
